# Work item relations require core-verifiable evidence

A future Issue-to-Change Request relation model will admit only the neutral
predicates `references` and provider-native `resolves`, with source Evidence and
repository-allowlist validation. Full URLs, provider-native linkage, and
unambiguous scoped references may become evidence-bearing inputs; bare `#iid`
or `!iid` tokens do not establish cross-object relations. Agent inference stays
an external candidate unless a future explicit human-confirmation contract
promotes it, so a Skill prompt cannot silently create canonical edges.
