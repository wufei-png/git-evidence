# Public release and privacy baseline

The project uses Apache-2.0 as its working license and may commit only
synthetic or demonstrably anonymous fixtures. Real private hosts, project
names, member identities, URLs, tokens, comment bodies, and internal report
examples stay out of the public repository. Comment bodies are disabled by
default, credentials are referenced rather than stored, and the default
product has no ranking, productivity score, or performance-evaluation output.

The baseline is deliberately stricter than “delete obvious secrets from the
current tree”: source history, fixtures, generated artifacts, and example
configuration must all pass the same public-data review before release.
