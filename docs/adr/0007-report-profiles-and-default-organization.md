# Report profiles and default organization

The default report profile is project/topic-first, followed by releases and
engineering changes, with an explicit section for verified but uncategorized
activity. The public project also provides several selectable common profiles,
including timeline, release-focused, and opt-in actor-summary views. Actor
summary is never the only default and does not calculate rankings or
productivity scores. Profiles control presentation only; canonical facts,
evidence, and coverage remain shared and language-neutral.
