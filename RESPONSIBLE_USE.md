# Responsible use

The report is an evidence-backed record of engineering activity in a declared
scope and time window. It is not a productivity score, employee ranking, or
performance evaluation.

Do not use the default output to:

- rank people by commit, pull request, review, or comment counts;
- infer work value, effort, quality, or absence from activity volume;
- label a commit as improper because its change association is unknown;
- treat an empty result as proof that no work occurred;
- make a personnel decision without context outside this data source.

The actor-summary profile is opt-in and intentionally carries a warning. Teams
that need attribution should configure a clear purpose, visible audience, data
retention limit, and review process before enabling names.
